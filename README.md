# MazoWheel Lite

MazoWheel Lite is a DIY Force Feedback (FFB) steering wheel project for PC racing simulators.

## Downloads
Download the latest firmware (.bin) and Windows GUI (.exe) from the Releases section.

## Features
- Force Feedback steering support
- Steering calibration
- Simple Windows control software
- Custom MazoWheel firmware

## Installation
1. Download the firmware and GUI.
2. Flash the firmware to the supported microcontroller.
3. Connect your steering wheel via USB.
4. Open the MazoWheel Lite GUI.
